2. OVERVIEW


These are the IEEE Std 1149.1 Boundary Scan Description Language (BSDL)
files generated by Xilinx. These BSDL files are boundary-scan models for
unconfigured Versal architecture devices.

For more information on BSDL files, see:
http://www.xilinx.com/support


3. SOFTWARE TOOLS AND SYSTEM REQUIREMENTS

These BSDL text files may be used on any computer platform.

4. DESIGN FILES

The included files are listed in the FileMap.txt file.  This is the
file from the Vivado BSDL directory that describes how each BSDL
file aligns to a specific part.


5. INSTALLATION AND OPERATING INSTRUCTIONS

Versal architecture device BSDL files can be retrieved from the following:
- From the Device Models area within the Xilinx Download Center at:
  https://www.xilinx.com/support/download
- From the following directory within a Vivado Design Suite installation:
  Vivado/<version>/data/parts/xilinx/versal/public/bsdl/


For use with boundary-scan test tools, follow these instructions:

A.      Use these files with your boundary-scan test tool to generate
        boundary-scan tests on an unconfigured device.
B.      Review the design warnings in the BSDL file for special test
        procedures.

7. AR76889 (https://support.xilinx.com/s/article/76889)

    Certain Versal devices can be affected by a 3-state output issue.
    See https://support.xilinx.com/s/article/76889 for affected devices and details.
    This issue affects the following JTAG functions and conditions:
       1. JTAG TDO errors might occur on leading 1-value least-significant output bits
           when the TDO (VCCO_503 power pin) operates at 3.3V or 2.5V and
           when JTAG tools do not include a work-around.
           See https://support.xilinx.com/s/article/76893 for details and work-arounds.
       2. The JTAG EXTEST vectors might fail at MIO or HDIO pins when these pins
           are operated at 3.3V or 2.5V and when JTAG tools do not avoid or work-around
           the issue conditions. See https://support.xilinx.com/s/article/76894
           for details and work-arounds.
    For JTAG tools that do not avoid, or do not include work-arounds, or that are
       unknown to avoid/work-around for the two listed issues, a special variant of
       the BSDL files for affected device-packages is provided in the
       AR76889_workaround subdirectory of this Versal BSDL download .zip archive.
       There special BSDL file includes the following variations:
       - Work-arounds for JTAG TDO https://support.xilinx.com/s/article/76893
         - IDCODE 1-value LSB bits changed to X-value (don't care).
           NOTE: Some tools might not accept this variation because the IEEE 1149.1
           requires a 1-value in the LSB bit position of the IDCODE. See comments in
           the BSDL file to revert this variation to the original IDCODE.
         - INSTRUCTION_CAPTURE 1-value LSB bit changed to X-value (don't care).
           NOTE: Some tools might not accept this variation because the IEEE 1149.1
           requires a 1-value in the LSB bit position of the INSTRUCTION_CAPTURE.
           See comments in the BSDL file to revert this variation to the original
           INSTRUCTION_CAPTURE value.
       - Work-arounds for JTAG EXTEST https://support.xilinx.com/s/article/76894
         - BOUNDARY_REGISTER output3 cells and output3 control cells for MIO and HDIO
           pins are changed to internal cells and the control cell safe value is set
           to keep the 3state output disabled. Thus, this BSDL model does not support
           output control functionality for MIO and HDIO--only input capture is supported.
         - The MIO and HDIO pin port type is changed from INOUT to IN, per the above.
